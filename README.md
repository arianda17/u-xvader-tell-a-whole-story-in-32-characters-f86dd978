# Tell a Whole Story in 32 Characters

`$5 Venmo For WiFi`

Run it with `node main.ts` — the program prints the single entry line to stdout.

An enterprising neighbor is selling WiFi access for five bucks via Venmo, advertised right in the network list. Anyone scrolling past that name pictures the scene next door: a knock, a phone tap, and a password quietly changing hands.
